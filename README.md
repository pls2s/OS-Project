# OS-Project — Banker's Algorithm
โปรเจกต์วิชา Operating Systems สำหรับจำลองและแสดง Banker's Algorithm
## เกี่ยวกับโปรเจกต์
โปรแกรมนี้จำลองการทำงานของ **Banker's Algorithm** ซึ่งเป็น Deadlock Avoidance Algorithm ที่ใช้ในระบบปฏิบัติการ ช่วยให้ระบบตัดสินใจได้ว่าควรจัดสรร resource ให้ process ได้อย่างปลอดภัยหรือไม่
## Features
- แสดง Allocation Matrix, Max Matrix, Available Resource
- คำนวณ Need Matrix
- ตรวจสอบ Safe State และแสดง Safe Sequence
- แจ้ง Error เมื่อค่า Allocation เกิน Max
